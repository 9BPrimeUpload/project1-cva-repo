# Crimson Valley Dev Academy

Create a premium, modern, professional website for “Crimson Valley Academy”, a Roblox game development academy operated by Crimson Valley Studios.

The academy teaches aspiring Roblox developers practical skills including Lua/Luau scripting, Roblox Studio development, game design, UI/UX, building, animation, VFX, debugging, optimization, monetization, and complete game development.

BRAND IDENTITY:

- Name: Crimson Valley Academy

- Parent organization: Crimson Valley Studios

- Style: premium, modern, technological, academic, professional

- Do NOT use a traditional school/college design.

- The website should feel like a professional game-development academy.

- Primary colors: deep navy / midnight blue, white, silver, and cool blue/cyan accents.

- Avoid excessive red despite the name “Crimson Valley”.

- Use subtle gradients, glassmorphism, soft glow effects, clean cards, elegant borders, and smooth animations.

- Use a high-quality dark theme as the default.

- Typography should be modern and highly readable.

- Fully responsive for desktop, tablet and mobile.

- Use the Crimson Valley Academy logo prominently in the navbar and footer.

- The design should feel trustworthy and premium rather than flashy.
